# STILL WORLD

A SUPERHOT-inspired top-down shooter game built with Pygame.

## 🎮 Game Description

Time moves only when you move! Defeat enemies, collect health packs, and survive as long as possible.

## 🎯 Features

- WASD movement (time slows when standing still)
- Shoot with Left Click or F key
- Two enemy types:
  - **Enemy1**: Normal enemy, 25 points, 33% health drop
  - **Enemy2**: Rare enemy (30% spawn), 40 points, 100% health drop
- Wall collision (player, enemies, bullets)
- Hit feedback with floating "Hit" text
- Level progression with increasing difficulty
- Pause (P) and return to main menu (M)
- Result screen with rank system (S/A/B/C)
